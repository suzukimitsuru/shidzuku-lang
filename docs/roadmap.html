3. ADR の検討順

ADR は互いを改訂する。改訂される側を先に採ると採用の直後に書き直しが要り、改訂する側を先に採ると依拠先が提案のままで宙に浮く。

  • ステップにまとめる — 改訂の関係にある ADR をまとめ、同時に採否を判断する。
  • ステップを並べる — 依拠の向き(名前 → 型 → 指針 → 接合面)に並べる。
  • いまの状態 — 2026-08-28 の採用(0005・0013・0015)と 2026-08-29 の採用(0014)でステップ1 は空になり、ステップ2 の一部も先に抜けた。残りだけを判断待ちとして示す。
  • ステップの番号は動かさない — 採用の記録と対応が付くようにするため。

4. Phase 0 の検証ループ

仕様だけを先行させないための往復。思考実験が仕様や ADR へ差し戻した所を、起きた順に並べる。

  • 〜2026-08-28 — 内部階層とシステムコンテキストが確定
    U1(意図)・U2(通信)・省略の禁止(ADR 0008)に続き、U3(ADR 0005・0013)と U18(ADR 0015)を採用した。配置の記述は ADR 0015 が「動作環境の設定として Phase 2 で決める」と答えた。
  • 2026-08-29 — 記述の表記が確定し、第5章が加わった
    U17(ADR 0014)を採用した。
  • 思考実験 07 → ADR 0017
    ADR 0010 の限界(近似が本質の計算が書けない)への差し戻しであり、このループが一周した例である。
  • 思考実験 08 → U19〜U21 を新設
    U19(検証番号の採番)は ADR 0016 で即日決着した。論点5 は解決したのではなく問い自体が消えた — ADR 0018(提案)が「1プログラム = 1システム」を外してシステムの入れ子(C4 の System Landscape)を許し、外部システムの判定基準を廃した(external に書いた物が外部システムである)ためである。
  • 思考実験 09 → U22 と ADR 0019
    ADR 0017 が数値型を軽くした副作用で 19 桁の値(ナノ秒の時点)の置き場所が消えていた事が、整数型を置く直接の理由である。これも思考実験が ADR へ差し戻した例である。
  • 思考実験 10 → ADR 0019 を同日に改訂
    6点の穴(時刻に長さを足せない・曜日が無い・整数の単位換算が無い・隔たりの桁溢れ 等)を見つけた。
  • 思考実験 11 → ADR 0020 の起案
    「元号は版が変わる表だから持たない」という判断が、退ける対象を取り違えていた事を示した。
  • ステップ2 の5本を採用し、第6章「データと型」を新設
  • 思考実験 12 → U23 を新設
    思考実験 01〜11 の全データを仕様書だけで書き直し、全て書けた上で5つの論点が出た。2つは仕様書の文面で閉じ、スカラー倍の穴が U23 となった。
  • 思考実験 13 → U24 を新設
    U23 への「数える値にも単位を持たせる」案を検証し、単位の軸と数値型の軸が直交している事(この案では U23 が解けない事)を示した。
  • 2026-09-03 — 4つの方向のうち3つを白紙から再検討
    U14 の論点は計画書 第5節に8つへ展開し、方向の上で残る問題は第6節に置いた。その上で書き手が次のように決めた。
    • 数値型(U23) — ADR 0010・0017 を破棄。思考実験 14 で金融機関(COBOL・BigDecimal・C# decimal)と科学技術計算(Fortran の KIND・単精度・区間演算)を比較し、7つの論点にまとめた
    • 名前空間(U14 論点4・5) — 逆ドメイン名を撤回。思考実験 15 で Java・Rust・Common Lisp・Unison 等を比較し、contains の木構造(ADR 0018)をそのまま名前空間にできる可能性を示した
    • 思考実験 16 → ADR 0021 の改訂 — 十進数(0) が任意精度の整数になったため、ADR 0019 が 整数 を置いた根拠は失効していた。書き手の指定(外部との接合は幅付き整数・時間の型は内部で整数保持でよい)を受け、整数 を基本型から外して数値型を2つにし、幅付き整数は境界の宣言に移した
    • 可視性のキーワード(U14 論点1) — expose の流用を撤回し、share を候補として提案した
    • 組み込みの区分名(U14 論点2) — 第6章 6.1 の指針(不在の区分名は何が無いのかを言う)と衝突するため、撤回のまま確定した
  • 判断待ち
    U5(ADR 0012)・U7(ADR 0006)・U14 の一部(ADR 0018)。残る U20・U21 は U4・U10〜U14・U16 と併せて順次検討する。詳細は計画書 第5〜7節にある。
