## 次に決める事

- 試作の間は、ADR 0027 の候補「出力言語で直に書く」を仮に使い、生成した Rust の骨組みに body を手で書く(計画書 第4節「仮置き」、ADR 0033(試作を先に置く進め方))
- 混在の試作の前に、試作で書いた body を材料に候補を書き比べ、ADR 0027 の決定を書く。失敗の体系(U13)と実行モデル(U10)の待つ所の印に依る
- 受けた入力を片付ける: [実行モデル](../実行モデル/README.md) の「他の領域への入力」(ADR 0032 の採用までは仮の入力)から、待つ所を印として読める形で書く事と、互いに依存しない `ask` を送り出してから並べて待てる事(ADR 0032 の決定5)。待つ所は三つ(決定2)。E0032-3(必ず期限切れになる `ask` の閉路)と W0032-2(効かない `exclusive`)は body を読む検査
