# 0022: 単位の種別 — 量を比率・計数・計量・位置に分けて宣言する

- 日付: 2026-09-17
- 状態: 採用(2026-09-17)
- 関連課題: U24・U15(関連: U9・U23・U13・U14)
- 位置づけ: ADR 0021(採用)の決定4(`unitless` とのスカラー倍)と決定11(添字・長さの型)を改訂する。ADR 0010 から引き継いだ量と単位の体系に、種別の欄を足す
- 入力: 思考実験 13・18・19、書き手の指定(2026-09-17。下記)

## 背景(なぜ決める必要があるか)

第6章 6.3 と ADR 0021 は、単位を持たない値を `unitless` で書いていた。その代表が次の3つである。

```plaintext
int64(0) unitless   # 個数・版・連番
uint64(0) unitless  # 列の添字・長さ
int64(4) unitless   # 税率(0.1000 = 10%)
```

この書き方には、それぞれ別の穴がある。

| 値             | 穴                                                                              |
| -------------- | ------------------------------------------------------------------------------- |
| 個数           | 件数と行数、`3 ケース` と `3 個` の取り違えが型で落ちない                       |
| 版・連番・添字 | 足し算に意味が無いのに `版 + 版`・`版 × 3` が書ける(U24)                        |
| 税率           | `10` と書くか `0.10` と書くかを注記でしか伝えていない。`税率 + 個数` も落ちない |

書き手から「これらも単位として指定してよいのではないか」という問いがあり、検討の上で次の2点が指定された(2026-09-17)。

- **数える量は、掛けると単位が消える。** `円 × 個 = 円` であり、単価は通貨として円・米ドルと同じ扱いにする。
- **単位を種別(足し算を禁じる・掛けると消える 等)に分け、書き手が量を定義できるようにする。**

思考実験 13(2026-08-29)は「数える値に単位を持たせても U23 は解けない」と結論していたが、その主な理由(次元は通るが型を跨ぐ)は
ADR 0021 で両辺が `int64` になって消えている。思考実験 19 で、残る障害を種別で解けるかを書き下ろして確かめた。

## 検討した選択肢

### 論点1 — 種別をどこまで書き手に開くか

| 案                                                             | 利点                                | 欠点                                                                    |
| -------------------------------------------------------------- | ----------------------------------- | ----------------------------------------------------------------------- |
| (a) 性質(足し算・掛け算の振る舞い)を書き手が自由に組み合わせる | 最も柔軟                            | 意味の無い組み合わせが書ける。同じ `×` の意味がプロジェクトごとに変わる |
| (b) **種別を言語が固定し、書き手は量を定義する時に種別を選ぶ** | 規則は言語が1つ持つ。量と単位は自由 | 種別を増やすには言語の改訂が要る                                        |
| (c) 種別を持たない(現状)                                       | 語彙が増えない                      | 数える量・比・順番を区別できない                                        |

(b) を採る。足し算(できる・差とだけ・できない)× 掛け算(残る・消える・できない)の9通りのうち、意味を持つのは3つしかない
(思考実験 19 の 2.1)。**自由に組ませても増えるのは無意味な組み合わせだけ**であり、固定しても表現力は落ちない。
足し算も掛け算もできない値(郵便番号・区分コード)は、数値型ではなく識別子型・直和で書く(第6章 6.2)。

### 論点2 — 計数どうしの乗除算

| 案                             | 利点                              | 欠点                                   |
| ------------------------------ | --------------------------------- | -------------------------------------- |
| (a) **組立の量の宣言を要する** | 計量どうしの規則(E0010-5)と同じ形 | `件 ÷ 人` のたびに量の宣言が要る       |
| (b) 左辺が残る                 | 宣言が要らない                    | 左右を入れ替えると結果が変わる         |
| (c) 両方消えて `unitless`      | 宣言が要らない                    | 何の数かが消え、書き手が単位を付け直す |

(a) を採る。書き手の指定「数える量は掛けると消える」の相手は計量(`円 × 個`)と比率であり、計数どうしの積は数えた物が2種類ある場面である。
**どちらを残すかを言語が決めると、読み手は左右の順を覚える事になる**(思考実験 19 の 10.1)。

### 論点3 — 比率の量をいくつ持つか

| 案                                                  | 利点                         | 欠点                                                            |
| --------------------------------------------------- | ---------------------------- | --------------------------------------------------------------- |
| (a) **言語が1つだけ持ち、書き手は単位だけを足せる** | 基準が 1 の量が1つに定まる   | `税率 + 割引率` を型で落とせない                                |
| (b) 書き手が比率の量を複数宣言できる                | 税率と割引率を別の量にできる | 基準が同じ 1 なのに足せない量が複数でき、往来に特別な規則が要る |

(a) を採る。比率の基準は必ず数の 1 であり、**何の比かは値の名前が言う**(`時間` を待ち時間と実行時間に分けないのと同じ)。

### 論点4 — 列の添字と長さの単位

| 案                                                 | 利点                              | 欠点                                                |
| -------------------------------------------------- | --------------------------------- | --------------------------------------------------- |
| (a) `unitless` のまま(ADR 0021)                    | 往来の手間が無い                  | 添字と長さの取り違え(off-by-one の一因)が型に出ない |
| (b) 要素の型ごとに単位が決まる                     | `list<明細>` の長さが `行` になる | 型引数に依存して単位が決まり、依存型に近づく        |
| (c) **言語が `要素`(計数)と `要素目`(位置)を持つ** | 添字と長さが型で分かれる          | `要素` と業務の計数(`件`)の往来に2段の操作が要る    |

(c) を採る。(b) は思考実験 13 の 3.3 が退けた形である。「注文の列の要素数が注文の件数である」は書き手の知識であり、
往来の手間はそれをソースに書かせる代償である(思考実験 19 の 8.1)。

## 決定

### 1. 量は4つの種別のいずれかに属する

| 種別     | 足し算                           | 掛け算                     | 基準                   | 例                         |
| -------- | -------------------------------- | -------------------------- | ---------------------- | -------------------------- |
| **比率** | 同じ量どうし                     | 消える                     | 数の 1 (`unitless`)    | パーセント・税率・歩留まり |
| **計数** | 同じ量どうし                     | 消える(相手が比率なら残る) | 数える単位             | 個・人・件・要素           |
| **計量** | 同じ量どうし                     | 残る(組立の量の宣言が要る) | 基準単位 / なし        | メートル・秒・円・米ドル   |
| **位置** | 差の量とだけ。位置 + 位置 は不可 | できない                   | 差の量の単位に対応する | 版・連番・添字・座標       |

- 換算の軸(`基準 <単位>` / `基準 なし`)は種別と独立しており、ADR 0010 以来の規則のままである。
- `位置` は、`時点` と `量 時間` の関係(第6章 6.4)を書き手が宣言できる形にしたものである。`時点` 自体は基本型のまま変えない。

### 2. 量の宣言に種別の欄を置く。既定は無い

```plaintext
量 <名前> <種別> 基準 <単位 | なし>
量 <名前> 位置 差 <差の量> 基準 <位置の単位>
量 <名前> <種別> = <量> × <量>              # 組立の量
単位 <名前> : <量> = <基準単位> × <比>

量   通貨   計量 基準 なし
単位 円     : 通貨
単位 米ドル : 通貨
量   個数   計数 基準 個
単位 ケース : 個数 = 個 × 24
量   版差   計数 基準 版
量   版番号 位置 差 版差 基準 版目
```

- **種別を書かない量の宣言は E0008-1** である(ADR 0008)。
- 種別の綴り(ASCII の語彙)は Phase 1 のパーサ実装で決める(第5章 5.3・ADR 0014)。本 ADR の日本語の表記は仮置きである。
- 組立の量の種別は書き手が書く。計量を含む組立は計量、計数どうしの組立は計数でなければならない(E0022-3)。

### 3. 比率の量は言語が1つだけ持つ。基準単位は `unitless`

```plaintext
単位 パーセント       : unitless = unitless × 1/100
単位 ベーシスポイント : unitless = unitless × 1/10000

税率: int64(2) パーセント   # 10.00 = 10%
```

- 書き手は比率の量に**単位だけを足せる**。比率の量を新たに宣言すると E0022-4 である。
- `unitless` の意味は「単位の欄が空である」から「**比率の量の基準単位(数の 1)である**」に変わる。書き方は変わらない。
- `復号` の結果は今のまま `unitless` である(ADR 0021 決定9)。計数・計量・位置の単位は `単位を付ける` で付ける。

### 4. 乗除算は強さの順で決まる — 比率 < 計数 < 計量

**掛け算は、強い方の単位が残り、弱い方が消える。** 同じ強さどうしは、比率を除いて組立の量の宣言が要る。

| 左辺 \ 右辺 | 比率       | 計数                 | 計量                 |
| ----------- | ---------- | -------------------- | -------------------- |
| 比率        | 比率       | 右辺の計数           | 右辺の計量           |
| 計数        | 左辺の計数 | 組立の量の宣言が要る | 右辺の計量           |
| 計量        | 左辺の計量 | 左辺の計量           | 組立の量の宣言が要る |

**割り算は、弱い方で割ると弱い方が消え、同じ量どうしで割ると比率になり、強い方で割るには宣言が要る。**

| 被除数 \ 除数 | 比率         | 計数                             | 計量                             |
| ------------- | ------------ | -------------------------------- | -------------------------------- |
| 比率          | 比率         | 組立の量の宣言が要る             | 組立の量の宣言が要る             |
| 計数          | 被除数の計数 | 同じ量なら比率。違えば宣言が要る | 組立の量の宣言が要る             |
| 計量          | 被除数の計量 | 被除数の計量                     | 同じ量なら比率。違えば宣言が要る |

```plaintext
金額   = 単価 × 数量                                  # int64(2) 円 × int64(0) 個 → int64(2) 円
一人分 = 分ける(合計, 人数)                            # int64(2) 円 ÷ int64(0) 人 → int64(2) 円
達成率 = 割る(実績件数, 目標件数, int64(2), 丸め 切り捨て)  # 件 ÷ 件 → int64(2) unitless
```

- 同じ量で単位が違えば、基準へ換算してから割る。換算比を持たない量は同じ単位どうしに限る(E0010-2)。
- 宣言の無い組立の量は E0010-5 のままである。本決定は、**どの組み合わせで宣言が要るか**を種別で定める。
- 幅・符号・位取りの規則は ADR 0021 決定5 のままである。

### 5. 比率の単位は、消える所で位取りに畳み込む

```plaintext
小計 × 税率   # int64(2) 円 × int64(2) パーセント → int64(6) 円(位取り 2 + 2 + 2)
```

- 比が 10 の負の冪(`1/100`)なら、その指数を位取りに足す。丸めは起きない。
- 比が 10 の正の冪なら `m` にその倍率を掛ける。溢れれば失敗である(ADR 0021 決定5)。
- 比が 10 の冪でなければ、消える所で丸めが避けられない。**丸めの宣言が無ければ E0010-3** である。
- 計数の単位(`ダース`)は、掛け算で消える時に比を掛けない。消えるのは単位であって、「1ダースあたり」という値の意味は欄の名前が言う。

### 6. 位置の量は、差とだけ足し引きし、比較と隔たりだけを持つ

```plaintext
新しい版 = 現在.版 + 1 版                        # 位置 + 差 → int64(0) 版目
上書き可 = 受信.版 > 現在.版                      # 位置どうしの比較
遅れ     = 隔たり(受信.版, 現在.版, int64(0))      # int64(0) 版

現在.版 + 受信.版                                 # E0022-1
現在.版 × 3                                       # E0022-2
```

| 演算                             | 結果              | 備考                                    |
| -------------------------------- | ----------------- | --------------------------------------- |
| `位置 + 差` / `位置 - 差`        | 位置              | 左辺が位置(`時点` と同じ)。範囲外は失敗 |
| 位置どうしの比較                 | `論理`            | 同じ位置の量どうしだけ                  |
| `隔たり(<始め>, <終わり>, <型>)` | `<型> <差の単位>` | 結果の型は符号付きに限る(E0022-5)       |
| `位置 + 位置`・`位置 - 位置`     | エラー(E0022-1)   | 隔たりは `隔たり(…)` で取る             |
| 位置の乗除算・`合算`             | エラー(E0022-2)   |                                         |

- 位置の量は**単位を1つだけ持つ**。単位は差の量の単位と同じ刻みで対応する(`版目` と `版`)。
- 位置の量の数値型は `int`・`uint`・`float` のいずれでもよい(`dec` は内部計算のみ。ADR 0021 決定5-3)。
- `隔たり` は丸めが起きないため丸めの欄を持たない。`時点` の `隔たり`(第6章 6.4)とは引数の形が違うが、同じ概念の同じ語である。
- リテラルの綴り(`1 版`)は Phase 1 で決める。

### 7. 言語が最初から持つ量を足す — `要素数` と `要素番号`

```plaintext
量 要素数   計数 基準 要素
量 要素番号 位置 差 要素数 基準 要素目
```

| 値           | 型(ADR 0021)         | 型(本 ADR)         |
| ------------ | -------------------- | ------------------ |
| 列の長さ     | `uint64(0) unitless` | `uint64(0) 要素`   |
| 繰り返し回数 | `uint64(0) unitless` | `uint64(0) 要素`   |
| 列の添字     | `uint64(0) unitless` | `uint64(0) 要素目` |

- **E0019-4 を改訂する。** 長さと繰り返し回数は `uint64(0) 要素`、添字は `uint64(0) 要素目` に限る。
- 長さを添字に使うには、原点に足して位置にする(`0 要素目 + 長さ(列) - 1 要素`)。
- 言語が持つ量は `時間`(計量)・比率の量・`要素数`・`要素番号` の4つになる。

### 8. 単価と金額は単位で区別しない

- 書き手の指定により、単価は `円` であり、金額と同じ単位である。**単価を金額の欄へ渡す誤りは型で落ちない。**
- 量と単位で落とすのは**次元の誤り**(長さ + 重さ、個数 + 税率)であり、同じ次元の中の役割の誤りではない。
  役割は欄の名前が言い、型で分けたい書き手は型の別名(ADR 0021 の将来の変更想定)で名前的に分ける。

### 9. 検証 — 5つ改訂、E0022 を5つ新設

| 識別子  | 検査                                                              | 本 ADR での扱い                                                           |
| ------- | ----------------------------------------------------------------- | ------------------------------------------------------------------------- |
| E0008-1 | 必須宣言の欠落                                                    | **改訂**。対象に「量の種別の欄」を加える                                  |
| E0010-1 | 異なる量の加減算・比較                                            | **改訂**。位置の量とその差の量の加減算は除く(決定6)                       |
| E0010-3 | 丸めが避けられない演算に丸めの宣言がない                          | **改訂**。比が 10 の冪でない比率の単位が消える所を加える(決定5)           |
| E0010-5 | 宣言のない組立の量の出現                                          | **改訂**。宣言が要る組み合わせを強さの順で定める(決定4)                   |
| E0019-4 | 列の添字・長さ・繰り返し回数の型                                  | **改訂**。長さと回数は `uint64(0) 要素`、添字は `uint64(0) 要素目` に限る |
| E0022-1 | 位置の量どうしの加減算、または位置の量と差の量以外との加減算      | **新設**                                                                  |
| E0022-2 | 位置の量の乗除算・`合算`                                          | **新設**                                                                  |
| E0022-3 | 組立の量の種別が構成する量と合わない(計量を含むのに計量でない 等) | **新設**                                                                  |
| E0022-4 | 比率の種別の量を書き手が宣言している                              | **新設**(決定3)                                                           |
| E0022-5 | 位置の `隔たり` の結果に符号なしの型を書いている                  | **新設**(決定6)                                                           |

実行時の失敗(U13)は増えない。位置 - 差 が範囲を出る事(空の列の末尾)は、ADR 0021 の「加減乗の結果が幅を出る」に含まれる。

### 10. 使い分けの指針

| 問い                               | 種別                           |
| ---------------------------------- | ------------------------------ |
| 同じ量どうしの比か                 | 比率(`unitless`・`パーセント`) |
| 物を数えた数か                     | 計数(`個`・`人`・`件`)         |
| 測った・払った量か                 | 計量(`メートル`・`秒`・`円`)   |
| 何番目か・どこか(足して意味が無い) | 位置(`版目`・`要素目`・座標)   |
| 足しも掛けもしないか               | 数値型にしない(識別子型・直和) |

## 机上検証(思考実験 19 の要約)

| 確かめた事               | 結果                                                                                        |
| ------------------------ | ------------------------------------------------------------------------------------------- |
| 明細の金額               | `int64(2) 円 × int64(0) 個` → `int64(2) 円`。強さの順で通る                                 |
| 税額                     | `int64(2) 円 × int64(2) パーセント` → `int64(6) 円`。比が位取りに畳まれ、注記が要らなくなる |
| ケースで仕入れて個で売る | `3 ケース` を `3 個` として足す誤りが落ちる                                                 |
| 按分                     | `分ける(円, 人)` → 円。思考実験 18 の 2.4 の詰まりは解けたまま                              |
| 一人当たり件数           | `件 ÷ 人` は組立の量の宣言を要する(論点2)                                                   |
| 版(U24)                  | `版目 + 版` は書け、`版目 + 版目`・`版目 × 3` は落ちる                                      |
| 列の添字と長さ           | `要素目` と `要素` に分かれ、長さを添字に使うには原点に足す事を書く                         |
| 座標                     | `float64 メートル地点` + `float64 メートル`。位置は整数だけの物ではない                     |

## 結果(利点と欠点)

### 利点

- **数える量・比・順番の取り違えが型で落ちる。** 件数と行数、ケースと個、税率と個数、版と版。
- **U24(序数と基数)が、新しい基本型を足さずに解ける。** `時点` が既に持っていた「点と差」の形を一般化しただけである。
- **スカラー倍の規則が1本になる。** ADR 0021 決定4 の「`unitless` との乗除算は単位を変えない」は、強さの順の特別な場合になった。
- **税率の意味が型から読める。** `int64(2) パーセント` は「10.00 が 10%」と読め、注記が要らない。比は位取りに畳まれ、丸めは起きない。
- **添字と長さが型で分かれる。** off-by-one の一因が型に出る。
- 種別は言語が固定するため、`×` と `+` の意味はどのプロジェクトでも同じである。量と単位は書き手が業務の語彙で自由に定義できる。
- 単位は型情報のみであり、実行時コストはゼロのままである。

### 欠点

- **量の宣言が増える。** 位置の量は差の量と対で2行になり、助数詞の数だけ計数の量が増える(思考実験 13 の 3.5 は残る)。
- **種別の欄を全ての量の宣言に書く。** 省略の禁止により既定は無い。
- **単価と金額は単位で区別できない**(決定8。書き手の指定による代償)。
- **`要素` と業務の計数の往来に2段の操作が要る**(`単位を外す` → `単位を付ける`)。
- **計数どうしの乗除算に量の宣言が要る**(論点2)。`件 ÷ 人` のたびに `一人当たり件数` を宣言する。
- **`税率 + 割引率` は落ちない**(論点3)。比率の量は1つである。
- **原点をずらした位置の単位を持たない。** 摂氏・華氏の絶対温度は位置の量だが、`計量 基準 なし` のまま残る。
- `隔たり` が `時点` 版と位置版で引数の形が違う。

### 総括 — 何と引き換えに何を得るか

**単位に「何の量か」だけでなく「どう計算してよいか」を言わせる。**
ADR 0010 は次元の誤り(長さ + 重さ)を落とした。本 ADR は、次元が 1 の値の中に埋もれていた3つの誤り——数えた物の取り違え、比の書き方の取り違え、順番の足し算——を、
種別という1つの欄で落とす。代償は宣言の行数であり、それは「この値は何番目か、いくつか、どれだけか」を書き手がソースに書く事そのものである。

## 捨てたもの・理由

- **性質を書き手が自由に組み合わせる案**(論点1 の (a)): 意味を持つ組み合わせは3つしかなく、自由にしても無意味な組み合わせが増えるだけである。
  種別の規則が記述ごとに変わると、読み手とコンパイラの双方で検証が重くなる。
- **単価を `円毎個` とする案**(思考実験 13 の 2.2): 次元としては正しいが、書き手の指定により採らない。単価は通貨として扱う。
- **計数どうしの積で左辺を残す案・両方消す案**(論点2 の (b)(c)): 左右の順を覚える事になるか、何の数かが消える。
- **比率の量を書き手が複数宣言できる案**(論点3 の (b)): 基準が同じ 1 の量が複数でき、往来に特別な規則が要る。
- **要素の型ごとに長さの単位が決まる案**(論点4 の (b)): 依存型に近づく(思考実験 13 の 3.3)。
- **序数を別の基本型にする案**(思考実験 13 の 3.4): 位置の種別で足りる。基本型を増やさない。
- **足し算も掛け算もできない種別を置く案**: そのような値は数値ではなく、識別子型・直和で書く(第6章 6.2)。

## 将来の変更想定

- **原点をずらした位置の単位**(絶対温度の摂氏・華氏・ケルビン)。位置の量が複数の単位を持ち、単位の間に比と原点のずれを持つ形。必要が確認されたら思考実験を回す。
- **型の別名**(`data 単価 = int64(2) 円`)。単価と金額の役割を名前的に分けたい場合の受け皿(ADR 0021 の将来の変更想定と同じ)。
- **情報量の量**(`バイト`・`ビット`)。`バイト列` の長さを `要素` ではなく `バイト`(計量)で持つか。テキストの層(ADR 0013)の長さと併せて検討する。
- **種別の綴り**。`ratio`・`count`・`measure`・`position` 等を Phase 1 で決める(`measure` は ADR 0015 が単位の語から外した経緯がある)。
- **量の可視範囲**(U14)。言語が持つ量が4つになり、書き手の量と並ぶ。
- 採用時の反映先:
  - 第6章 6.3 の「量と単位」に種別の欄・強さの順・比率の畳み込み・位置の演算を書き、数値型の例(`int64(0) unitless` 等)を本 ADR の単位に改める。
  - 第6章 6.3 の「列の添字・長さ・繰り返し回数」を決定7 に改める。
  - 第3章 3.3 の E0008-1・E0010-1・E0010-3・E0010-5・E0019-4 を改訂し、E0022-1〜E0022-5 を加える。
  - 第5章 5.3 の「数値の量と単位」に種別の語彙を加える。
  - ADR 0021 の決定4・決定11 を本 ADR が改訂する旨を記録する。
