# 0002: プロジェクト名の再考

- 日付: 2026-08-18
- 状態: 採用
- 関連課題: なし(U1〜U8 の外だが、命名の経緯を残すため ADR とする)

## 背景(なぜ決める必要があるか)

`shizuku-lang` を Google 検索すると、Android アプリの
[Shizuku](https://github.com/RikkaApps/Shizuku)(RikkaApps)とその関連プロジェクト群、
アニメ・ゲームのキャラクター名などが多数ヒットし、本プロジェクトを特定できない。
雫(しずく)という読みは維持したまま、検索で一意に特定できる綴りが必要になった。

## 検討した選択肢

Web 検索で各候補の競合状況を確認した。

| 候補          | 検索結果                                          | 判定 |
|---------------|---------------------------------------------------|------|
| `shizuku`     | Android アプリ Shizuku が支配。アニメ・人名も多数 | 除外 |
| `sizuku`      | 既存の開発ツール(Drizzle スキーマ生成)と衝突      | 除外 |
| `shizuq`      | 日本の飲料ブランドが実在                          | 除外 |
| `siduku`      | カンナダ語の単語・姓・SNS ハンドルで使用例あり    | 弱い |
| `shizukulang` | 完全一致なし。ただし部分一致で shizuku と混ざる   | 次点 |
| `shidzuku`    | ソフトウェア・ブランドとしての完全一致なし        | 採用 |

## 決定

プロジェクト名を **`shidzuku-lang`** とする。パッケージ名・CLI 名は `shidzuku` を用いる。

- 読みは「しずく」のまま変えない
- 綴りは雫の歴史的仮名遣い「しづく」のローマ字表記(づ = dzu)に由来する。
  語源まで遡った命名であり、「設計意図から実装までを一本の記述で貫く」という言語の思想とも整合する
- `"shidzuku"` の引用符付き検索や GitHub 検索でほぼ一意に特定できる

## 捨てたもの・理由

- **`shizuku`(現状維持)**: Android アプリ Shizuku に検索結果を支配され、特定できないため。
- **`sizuku`**: 既存の開発ツール([nakita628/sizuku](https://github.com/nakita628/sizuku)、Drizzle スキーマ生成)と衝突するため。
- **`shizuq`**: 既存の飲料ブランド([shizuq](https://shizuq-water.stores.jp/))と衝突するため。
- **`siduku`**: 使用例が散在する上、綴りから「しずく」の読みを推測しにくいため。
- **`shizukulang`**: `shizuku` を含むため部分一致で Android アプリ勢と混ざりやすく、独自性で `shidzuku` に劣るため。

## 将来の変更想定

- 引用符なしの Google 検索では `shidzuku` が `shizuku` に正規化されて類似結果が混ざる可能性がある。
  プロジェクトがインデックスされれば完全一致が上位に来る想定だが、実用上問題が残る場合は再検討する。
- 将来パッケージレジストリ(npm / crates.io / PyPI 等)へ公開する際は、事前に `shidzuku` の空きを再確認する。
