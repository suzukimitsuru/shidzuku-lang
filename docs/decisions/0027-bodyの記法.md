# 0027: body の記法

- 日付: 2026-09-28
- 状態: 提案(起票。決定は思考実験で候補を書き比べてから書く)
- 関連課題: U26(body の記法)。関連 U13(失敗の体系)・U10(実行モデル)・U5(トランスパイル先、ADR 0012)

## 背景(なぜ決める必要があるか)

コンポーネントの第三層(body)は、第2章 2.4 で「原則自由(ミュータブル・例外可)。言語が管轄するのは外側との通信のみ」とされたまま、**記法が決まっていない**。
思考実験 01〜26 は、どれも body を `body { ... }` のまま書いてきた。

Phase 1 の成果物は「三層記述を持つコンポーネントを 2〜3 個接続したプログラムが動く」事であり、body が書けなければ成り立たない。

- パーサの大半とトランスパイラの本体は、body の記法で決まる。
- 移行点検(計画書 第4節 4.5 の M4)は、成果物の題材を最新の仕様だけで書き下ろす。body が書けなければ書き下ろせない。
- 採用済みの決定のうち、次の物は body の中で効く。記法はこれらを破らない形でなければならない。
  - ADR 0005・0013: 内部階層の制約強度(`pure` / `io`)と役割(boundary / parse / domain / format)。body の全てのコードはいずれかの層に属する
  - ADR 0008: 既定値を置かない(省略の禁止)
  - ADR 0012 決定8: `pure` と役割の検査は Shidzuku 側で完結させ、出力先の言語に預けない
  - ADR 0014: 言語の語彙は ASCII、記述者の名前は UTF-8
  - ADR 0021・0022: 暗黙の変換を置かない。`dec(i.f)` は内部計算にだけ使う。単位と量の種別
- 未決の課題のうち、次の物が body の書き方を左右する。
  - U13 論点2(思考実験 22): 数値と解析の失敗を、body の中でどう受けるか(直和にする・伝播の記法・境界の操作に閉じ込める)
  - U10 と思考実験 24 論点2・3: `ask` を送り出してから待てるか、待つ所を印として body に現すか
  - 思考実験 26 論点2: 直和の分岐に「残り全部」を書けるか
  - 思考実験 24 論点5・6: 元の記述への対応表、出力言語で直に書く逃げ道

見直し前の計画書(第4節 4.5)は「構文規則(文法)を書く時期」を問うていたが、それは宣言の層も含めた形式文法を文書にする時期であった。
記法そのものの選択は、それとは別の問いである。本 ADR は後者を扱う。形式文法の文書化は、パーサの実装と同時に行う(計画書 第4節 4.5)。

## 検討した選択肢

組み合わせも候補に含める。たとえば、B-5 を軸に B-2 の網羅の分岐と失敗の伝播、B-1(Hike)の待つ所の印を借りる形である。

### 比べる物差し

1. 既定値を置かないか(ADR 0008)
2. 暗黙の変換を置かないか(ADR 0021)。単位と量の種別を式に通せるか(ADR 0022)
3. 役割ごとのテキスト操作を、構文の上で区別できるか(ADR 0013)
4. `pure` の検査を Shidzuku 側で行えるか(ADR 0005・0012 決定8)
5. 失敗の値の受け方(U13)と、待つ所の印(U10)を素直に書けるか
6. Rust と TypeScript の両方へ写せるか(ADR 0012)。3言語目以降(Hike を含む)の妨げにならないか
7. 宣言の層と語彙・構文の調子が揃うか(ADR 0014。一本の記述で貫く)
8. body に足す検査が、既存の言語に移せるか(ADR 0026 決定6)

## 決定

**未記入。** 本 ADR は起票の段階である。

- 次の行動: 同じ body——思考実験 04 の KVCore の格納と、思考実験 01 系(20・21・25 を含む)の受注——を候補ごとに書き比べる思考実験を起こす。
  物差し1〜8 で比べ、書けない所と擦れる所を並べる。
- 決定は、U13(失敗の体系)と U10(実行モデル)の ADR が失敗の値と待つ所の扱いを決めた後に書く(計画書 第4節 4.3・4.5)。
  書き比べの思考実験は、それより先に始めてよい。
- 決定を書く時は、body に足す検査ごとに、既存の言語に移せるか(思考実験 26 の4つの判定)を一行添える(ADR 0026 決定6)。

## 捨てたもの・理由

まだ無い。B-3 と B-6 は、採用済みの決定と擦れる所が大きい(B-3 は ADR 0008・0021、B-6 は ADR 0012 決定8)。
ただし書き比べの前に捨てず、擦れる所を具体に示す比較の対照として残す。
