# 採番台帳

思考実験・ADR・課題の番号と名前と領域の一覧。状態は書かない(状態は担当する領域の README に書く)。
番号は、並列の検討の枝を切る前に main の上で予約する。二つの枝が同じ番号を取らないようにするためである。

- 次に使う番号: ADR 0034・思考実験 34・課題 U27

## 予約の手順

1. main の上で、次に使う番号を取り、下の表に番号・名前・領域の行を足し、「次に使う番号」を進める
2. 予約した番号のファイルは、担当する領域の検討の枝で作る(予約の時には作らなくてよい)
3. 予約を commit してから、検討の枝を切る
4. 予約した番号を使わなくなったら、行を消さずに名前の後に「(欠番)」と書く
