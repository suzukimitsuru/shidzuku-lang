# runtime — Shidzuku の動作環境

[全体](../docs/PLAN.md) › runtime

- 状態: 細い縦の試作の範囲を動かす(2026-11-07)。分散は最小の分散動作環境(Phase 2)

動作環境は意味の核と器に分ける([ADR 0029(最小の動作環境)](../docs/decisions/0029-最小の動作環境.md) の決定1(意味の核を1つのクレートにする))。

| クレート                | フォルダ                | 中身                                                                                      |
| ----------------------- | ----------------------- | ----------------------------------------------------------------------------------------- |
| `shidzuku-runtime-core` | [core](core/src/lib.rs) | 意味の核。標準ライブラリに依らない。待ち行列と `pressure`、期限の判定、記述子の照合と能力 |
| `shidzuku-runtime-pc`   | [pc](pc/src/lib.rs)     | PC の器。時計(OS の経過時間計)・ロード(Rust の同居)・一本の非同期の実行系・試験の口       |

ESP32 の器は最小の分散動作環境(Phase 2)で作る。意味の核が素の目標で組める事は、次で確かめられる。

```sh
rustup target add riscv32imac-unknown-none-elf
cargo build -p shidzuku-runtime-core --target riscv32imac-unknown-none-elf
```

## 接合面

コンポーネントと動作環境の境目は、ADR 0012(動作環境の言語とトランスパイル先の言語)の接合面である。細い縦の試作で通したのは次の三つである。

| 呼び出し                        | 器の関数                               |
| ------------------------------- | -------------------------------------- |
| 結合(1つ目)                     | `動作環境::結合`                       |
| 流す(4つ目)                     | `出口::流す`                           |
| 流れを受ける・受領を返す(5つ目) | `受け口群::受ける`・`受け口群::終えた` |

- 接合面を流れるのは正準形のバイト列と型の指紋だけであり、器は値を解釈しない(ADR 0012 の決定4(接合面を流れる物))
- 接合面はまだ仮である。TypeScript のコンポーネントが通った時に凍結する(ADR 0012 の決定10(凍結の時期))
- 再起動(`restart`)・`durable`・版は、再起動と版の入れ替えの試作で足す。能力の `durable` は今は偽であり、`durable` を要る記述子は結合の時に拒む

## 試作の中で仮に決めた事

- コンポーネントの中は逐次、接続の中は FIFO(先入れ先出し)(ADR 0032(実行モデルと順序保証)の決定1(コンポーネントの中は逐次)・決定8(接続の中は FIFO)。提案。計画書 第4節「仮置き」)
- `bound` は待ち行列に並ぶ物と仕掛かりの物の和を数える(ADR 0032 の決定6(上限を `bound` で書く))
- ルートの system の公開面(試験の口)は `block`(期限は無期限、上限 64)に決め打つ。書く場所が無いため(外部との境界(U12)の仮置き)
